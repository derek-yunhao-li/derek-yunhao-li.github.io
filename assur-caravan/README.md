# The Assur Caravan

Open index.html through this GitHub Pages site. No installation is needed.

Editable game data: rules.js. Engine: engine.js. Student prose: guide.js. UI: app.js and style.css. Run developer tests with `node --test tests/*.test.js` in this folder (Node is for developers only).

The student design is the Guide tab; student-design.md is a text copy. The instructor design is delivered separately, not published here. The alignment manifest fingerprints this release.

Public source and downloaded saves can be inspected. Each team plays independently; no accounts, server, analytics, or multiplayer are used.
