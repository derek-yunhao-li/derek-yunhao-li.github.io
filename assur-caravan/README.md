# The Assur Caravan — website 2.3.0

Browser game. No installation required. See the repository README for editing, tests, research notes and GitHub Pages setup.

Edit `about.html` for the introduction, credits and contact information; `rules.js` for numerical rules; `guide.js` for player instructions.

The iron limit is two completed purchases per season. Declining an offer does not count. Textiles have the higher typical return. Older-version saves require a new game.

The independent repository is prepared locally with its GitHub Pages workflow.
Its creation still requires GitHub sign-in; this copy remains at the existing
website address until migration is completed.

Run `npm test` here for 72 checks or `npm run audit` for the balance comparison.
See `HISTORICAL_NOTES.md` for research and controlled simulation results.
